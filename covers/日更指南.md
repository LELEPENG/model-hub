# MODEL HUB · 每日封面工厂 · 使用指南

> 一套版式，6 个平台尺寸，每天只改一个数字，30 秒重出全套封面。

## 一、每天 3 步日更（约 30 秒）

| 步骤 | 操作 | 说明 |
|---|---|---|
| 1 | 打开 `cover-data.js` | 把 `COVER.rank` 改成今天要讲的名次（1–20），`COVER.day` 改成第几天 |
| 2 | 运行 `python export_covers.py` | 6 个尺寸自动重出，存到 `covers\out\` |
| 3 | 发视频 | 每张图文件名带 `day03_rank08_` 前缀，直接对号入座 |

临时想换名次不改文件：`python export_covers.py --rank 8`

## 二、6 个尺寸对应关系

| 文件后缀 | 尺寸 | 比例 | 用在哪 |
|---|---|---|---|
| `xhs-3x4` | 1080×1440 | 3:4 | **小红书主封面**（信息流展示面积最大） |
| `xhs-1x1` | 1080×1080 | 1:1 | 小红书次图 / 朋友圈 / 合集封面 |
| `dy-916` | 1080×1920 | 9:16 | **抖音 / 视频号竖版视频封面**、片尾定格 |
| `wxch-67` | 1080×1260 | 6:7 | 视频号信息流推荐比例 |
| `bili-169` | 1920×1080 | 16:9 | **B站 / YouTube 横版封面** |
| `mp-235` | 1080×460 | 2.35:1 | 公众号首图 / 社群转发卡片 |

> 平台实际裁切提示：抖音信息流会把 9:16 裁成约 3:4，所以**竖版封面的大数字和标题都放在上半屏**，不会被裁掉。

## 三、文件结构

```
covers/
├── cover.html          封面工厂本体（浏览器打开 = 预览导览页）
├── cover-data.js       ★ 每天只动这个：rank / day / 文案 / 尺寸预设
├── cover-fx.js         离子场（确定性渲染，同一天出图完全一致）
├── export_covers.py    批量导出脚本（调用本机 Chrome，无需装任何包）
├── fonts/              Outfit + JetBrains Mono 本地字体（断网也能出图）
└── out/                成品 PNG
```

## 四、文案怎么改（cover-data.js）

- `HOOKS`：每个名次一句钩子（封面最大的那句话）。改文案只动这里，**不要动版式**。
- `SUBLINE`：钩子下面的小字说明。留空则自动用 data.js 里该模型的 `best`。
- `COVER.cta`：底部统一引导语（所有天共用）。
- `COVER.seed`：离子纹理随机种子。想换背景纹理就换个数字，不想动就不用管。

**改版式的红线**：颜色字号都由当日模型的 `accent` 自动联动（第 8 名 = 琥珀、第 11 名 = 绯红……），不需要手动配色。

## 七、常见问题

- **导出尺寸不对 / 报错**：确认本机 Chrome 在 `C:\Program Files\Google\Chrome\Application\`（脚本自动探测，找不到会提示）。
- **想加新平台尺寸**：在 `cover-data.js` 的 `PRESETS` 加一行 `{ id, w, h, s, plat, use }`，重跑导出即可；版式会按宽高比自动选择竖/方/横/条幅模板。
- **字体显示不对**：`fonts/` 目录必须和 cover.html 放在一起（已就位，别删）。
- **离子背景想更密/更稀**：`cover-fx.js` 第 66 行 `area / 8600`，数字越小越密。
